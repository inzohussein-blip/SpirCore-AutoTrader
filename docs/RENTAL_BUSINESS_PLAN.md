# 📈 خطة تأجير البوت للمشتركين / Bot Rental Business Plan

خطة عملية لتحويل SpirCore إلى خدمة يشترك بها عملاء — مع تقليل المخاطر القانونية والتقنية.

> ⚠️ **ليست استشارة قانونية.** تأجير أنظمة تداول/إشارات خاضع لتنظيمات مالية تختلف بين الدول. راجع محامياً مختصاً قبل قبول أي مشترك يدفع.

---

## 🎯 القرار: النموذج (B) — النسخ المركزي (Centralized Copy-Trading)

بعد موازنة الخيارين، **النسخ المركزي هو المسار الموصى به للبداية**:

| المعيار | (A) حسابات مُدارة / لوحة تربط حساب العميل | (B) نسخ مركزي (ماستر → متابعون) |
|---|---|:---:|
| المسؤولية القانونية | إدارة أموال الغير = نشاط **مرخّص** (PAMM/MAM) | أخف (مزوّد إشارات) ✅ |
| بيانات العميل | تحمل كلمات مرور تداول العملاء (خطر هائل) | لا تلمس حساب/كلمة مرور العميل ✅ |
| سيطرة العميل على ماله | ناقصة | كاملة ✅ |
| الأمان (سطح الهجوم) | ضخم | محدود ✅ |
| التكلفة/التعقيد | نسخة MT5 لكل عميل / MAM | حساب ماستر واحد ✅ |
| سرعة الإطلاق | بطيء | سريع ✅ |
| جاهزية الكود عندنا | صفر | **signal relay + follower bot + تراخيص + أدمن** جاهزة ✅ |

**الخلاصة**: ابدأ بـ (B). الخيار (A) هو عمل **إدارة أصول مرخّص** — لا تبدأ به إطلاقاً قبل ترخيص قانوني.

## 🔒 الشرط الحاسم الذي يسبق كل شيء (Phase 0)
**لا تقبل أي مشترك قبل إثبات أفضلية حقيقية.** بيع نظام غير مُثبَت = خسارة أموال العملاء + مسؤولية قانونية + تدمير السمعة.
- [ ] تشغيل الماستر على **Demo** ثم **حساب حقيقي صغير** 2–3 أشهر على الأقل.
- [ ] **سجل مُدقَّق علنياً**: Myfxbook / FXBlue / MQL5 Signals (تتبُّع لا يمكن تزويره).
- [ ] مقاييس مقبولة: Profit Factor مستقر، أقصى تراجع محتمَل (Max DD) معلن بوضوح، عدد صفقات 100+.
- [ ] تشغيل `backtest.py --walkforward` لتأكيد أن الأفضلية ليست overfitting.

> بدون هذا، أوقف الخطة. الباقي بناء على رمل.

## 🛤️ الخطة المرحلية (بعد اجتياز Phase 0)

### Phase 1 — الإطلاق السريع عبر منصات جاهزة (أقل مخاطرة)
الأسرع والأقل مسؤولية: استخدم بنية البروكر/MQL5، لا بنيتك بعد.
- انشر الماستر على **MQL5 Signals Marketplace** أو **Social/Copy Trading** لدى بروكرك.
- المنصة تتولّى: الفوترة، التحقق، النسخ، العقود، إخلاء المسؤولية.
- أنت فقط تشغّل الماستر 24/7 (على **VPS** قرب سيرفر البروكر لتقليل الانزلاق).
- **التعلّم**: تجمع مشتركين وسجلاً عاماً دون بناء منصة.

### Phase 2 — منصتك الخاصة (تحكم كامل + حماية الكود)
انتقل لبنيتنا الجاهزة عندما تريد استقلالاً عن المنصات وحماية الكود المصدري:
- **الماستر** = `SpirCore_EA` على VPS عندك، مع `SAAS_PUBLISH=true` يبثّ الإشارات.
- **المشترك** = `SpirBot_Follower.mq5` على حسابه (أو VPS)، يستطلع قناتك.
- **التراخيص** = `saas/` (مفتاح لكل مشترك مربوط بحسابه + انتهاء) — الكود المصدري يبقى على سيرفرك.
- **لوحة الأدمن** `/admin` لإصدار/إلغاء التراخيص ومتابعة المشتركين.
- **صفحة الأداء** `/p/{key}` عامة للتسويق.
- **النشر**: `saas/Dockerfile` على أي مزوّد (Fly.io / Render / VPS).

### Phase 3 — التوسّع والأتمتة
- **Stripe حقيقي**: ربط `/billing/webhook` (تحقق التوقيع) ليُجدّد/يُلغي الترخيص آلياً عند الدفع/الإلغاء.
- **تسهيل المشترك**: مثبّت بنقرة واحدة للـ follower، أو VPS مُهيّأ مسبقاً تمنحه له.
- **دعم ومراقبة**: إشعارات (موجودة)، مراقبة توقف الماستر، تنبيهات تراجع.
- **(اختياري ومتقدّم)** الخيار (A) المُدار — فقط بعد ترخيص مالي ومحامٍ.

## 💰 نماذج التسعير (اختر واحداً)
| النموذج | الوصف | ملاحظة قانونية |
|---------|-------|----------------|
| **اشتراك شهري ثابت** | رسم شهري للوصول للإشارة/الترخيص | الأبسط والأأمن قانونياً ✅ |
| **رسم أداء (Performance fee)** | نسبة من أرباح العميل | غالباً **منظّم** (يشبه إدارة أصول) — احذر |
| **مجاني + عمولة بروكر (CPA/Rebate)** | تكسب من البروكر عبر رابط إحالة | شائع في MQL5 Signals |

**التوصية للبداية**: اشتراك شهري ثابت عبر MQL5 Signals (Phase 1).
