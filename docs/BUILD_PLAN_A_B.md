# 🏗️ خطة البناء الموحّدة — الوضعان A و B / Unified Build Plan (A + B)

في **كلا الوضعين لا ندير أموال العميل**: المال يبقى في حساب العميل، وهو يشاهده ويغلق صفقاته بنفسه. نحن نقدّم البوت/الإشارة فقط. هذا يقلّل المخاطر القانونية جوهرياً (خدمة أدوات/إشارات، لا إدارة أصول).

> ⚠️ ليست استشارة قانونية؛ ويبقى شرط **إثبات الأفضلية بسجل مُدقَّق** (Phase 0) قبل أي مشترك يدفع.

---

## الوضعان
| | **(A) ذاتي (Self-Serve)** | **(B) نسخ مركزي (Copy)** |
|---|---|---|
| أين يعمل البوت؟ | على حساب العميل (جهازه/VPS خاص به) | الماستر عندك يبثّ، المتابع على حساب العميل |
| ماذا يربط العميل؟ | حسابه بلوحة تحكمه | ترخيصه بقناة الماستر |
| تحكم العميل | يشاهد + يغلق + يشغّل/يوقف من لوحته | يشاهد + يغلق على منصته (نسخة المتابع) |
| ما يناسبه | من يريد التحكم الكامل بإعداداته | من يريد "اضبط وانسَ" |
| مبنيّ من؟ | `SpirCore_EA` + `bridge` + `dashboard` | `saas /signals/*` + `SpirBot_Follower` |

العميل يختار الوضع من **بوابة العميل** الموحّدة.

## ما هو مبنيّ بالفعل ✅ وما نحتاج بناءه 🔨
| القطعة | الوضع | الحالة |
|--------|:---:|:---:|
| تنفيذ ECN + استراتيجيات + مخاطر + إدارة صفقات | A | ✅ `SpirCore_EA` |
| لوحة تحكم حية (مشاهدة/إغلاق/تشغيل) | A | ✅ `bridge/dashboard.html` |
| بثّ الإشارات من الماستر | B | ✅ `SAAS_PUBLISH` + `/signals/*` |
| بوت المتابع | B | ✅ `SpirBot_Follower.mq5` |
| تراخيص + انتهاء + أدمن | A+B | ✅ `saas/` |
| صفحة أداء عامة | A+B | ✅ `/p/{key}` |
| **بوابة عميل موحّدة (تسجيل دخول + اختيار الوضع)** | A+B | 🔨 **نبنيها الآن** |
| تسجيل دخول للوحة التحكم (لكل عميل) | A | 🔨 لاحقاً |
| توصيل Stripe الحقيقي | A+B | 🔨 Phase 3 |

**الخلاصة**: البنية شبه مكتملة. القطعة المفقودة الجوهرية = **بوابة العميل** التي توحّد تجربة الدخول واختيار الوضع.

## مراحل البناء

### Phase 1 — بوابة العميل (الآن)
- `GET /me?key=` : يتحقق من ترخيص العميل ويعيد (الخطة، الانتهاء، القناة، الحساب).
- `GET /portal` : صفحة واحدة — العميل يُدخل مفتاح ترخيصه مرة، فيرى حالته + **بطاقتين**:
  - **الوضع A**: زر "افتح لوحة تحكمك" + خطوات تشغيل الجسر على جهازه.
  - **الوضع B**: قناة الماستر لمتابعتها + خطوات بوت المتابع.
- إعدادات: `SAAS_MASTER_CHANNEL` (قناة الماستر)، `SAAS_DASHBOARD_URL` (رابط لوحة الوضع A).

### Phase 2 — تسهيل التسليم
- **A**: حزمة مثبّت للجسر (أو VPS مُهيّأ) تُعطى للعميل بنقرة.
- **B**: تعليمات/مثبّت للـ follower.
- تسجيل دخول للوحة التحكم مربوط بالترخيص (بدل التوكن اليدوي).

### Phase 3 — الفوترة والتوسّع
- **Stripe** حقيقي (`/billing/webhook`): الدفع يُصدر/يجدّد الترخيص؛ الإلغاء يوقفه.
- مراقبة، دعم، إشعارات توقّف الماستر.

## التدفق للعميل (كلا الوضعين)
```
يشترك ويدفع ─► (Stripe) يُصدر ترخيصاً ─► يدخل /portal بمفتاحه
   ├─ اختار A: يشغّل الجسر على حسابه ويفتح لوحته (يشاهد/يغلق/يضبط)
   └─ اختار B: يشغّل بوت المتابع ويتابع قناة الماستر (يشاهد/يغلق على منصته)
الترخيص ينتهي ─► البوت يتوقف تلقائياً (InpUseLicense)
```
